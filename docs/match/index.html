      How pairs are decided

      Each possible pair is scored from both sides equally: a mutual first choice is the best score, then first and second, and so on. Mutual first choices are always paired. Everyone else is paired so that the group as a whole gets the best total score, which avoids leaving the last few people with whoever is left. Your ranking is private to the organizers.
